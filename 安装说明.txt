慢慢来 · 学习生活工作台 — 安装包
桌面端将以“老弟”称呼你；未完成的昨日待办会在次日首次打开应用时得到一次温和提醒。

手机浏览器安装
应用网址：https://leo678910674.github.io/copilot-hack/
Android：用 Chrome / Edge 打开网址，点击页面上的“安装应用”或浏览器菜单中的“安装应用”。
iPhone / iPad：用 Safari 打开网址，点“分享”→“添加到主屏幕”。
首次安装须联网下载离线应用；之后即使离线也可以从桌面图标打开。

Windows 桌面
1. 解压 ZIP 至一个方便保留的位置。
2. 双击“安装.cmd”，应用会在默认浏览器打开。
3. 点击页面顶栏的“安装应用”，或使用 Edge / Chrome 菜单中的“安装此应用”。
4. 安装完成后，可直接从 Windows 开始菜单或桌面启动“慢慢来”。

首次打开联网后，应用资源会保存在浏览器内，之后可离线使用。待办、课程、打卡和账目数据保存在当前设备上的浏览器内；卸载浏览器应用或清除浏览器站点数据前请先备份重要信息。

数据迁移：在“数据都由你掌握”区域导出 JSON 备份。请在其他设备打开已发布的安全 HTTPS 应用，再导入该备份。每个设备浏览器各自保存数据。

注意：这是可安装的跨平台浏览器 PWA 应用，不是原生 Android APK 或 Windows EXE。无需安装 Node.js、Java 或其他第三方软件。
