桌面端将以“老弟”称呼你；未完成的昨日待办会在次日首次打开应用时得到一次温和提醒。

手机浏览器安装
应用网址：https://leo678910674.github.io/copilot-hack/
Android：用 Chrome / Edge 打开网址，点击页面上的“安装应用”或浏览器菜单中的“安装应用”。
iPhone / iPad：用 Safari 打开网址，点“分享”→“添加到主屏幕”。
首次安装须联网下载离线应用；之后即使离线也可以从桌面图标打开。

Windows 桌面
1. 下载 `manmanlai-windows-installer.exe`，无需 ZIP 或解压。
2. 双击 EXE 安装程序；安装完成后会自动启动应用，并在桌面和开始菜单创建“慢慢来”快捷方式。
3. 使用期间保持随应用打开的本机服务窗口运行；关闭此窗口即可停止服务。首次打开联网后，应用资源会保存在浏览器内，之后可离线使用。

首次打开联网后，应用资源会保存在浏览器内，之后可离线使用。初次使用时课程、待办、打卡、目标、账目和预算均为空白，由你自行编辑。待办、课程、打卡和账目数据保存在当前设备上的浏览器内；卸载浏览器应用或清除浏览器站点数据前请先备份重要信息。

从旧版升级时，应用会自动移除未修改的内置演示条目及 2500 元预设生活费预算，并保留你修改过的条目、自行新增的数据和其他预算。每月预算未设置时，可在生活费账本中点击“未设置”来录入。

数据迁移：在“数据都由你掌握”区域导出 JSON 备份。请在其他设备打开已发布的安全 HTTPS 应用，再导入该备份。每个设备浏览器各自保存数据。

说明：Windows EXE 是免解压安装程序，会在当前 Windows 用户下安装应用资源并创建快捷方式；应用以本机浏览器运行。手机使用可安装 PWA，不是原生 Android APK。无需安装 Node.js、Java 或其他第三方软件。
